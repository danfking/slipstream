# What's real and what's synthetic

- The marina is synthetic, modelled on DockMaster's public module structure
- Findings were seeded on purpose; every run is identical, so what you saw is what anyone sees
- The whole record is browsable from the app: inspect the exact rows behind any answer
- Partner data trails are mocked, not the products; Blu bookings appear with their source attributed
- One assumption stated plainly: if Blu does not yet write to the record, that integration is the first partnership job

### Out of scope, on purpose

- Login, real ERP sync, writes beyond the approval gate, billing
- A written backlog: model variance accepted, interface polish mostly since built, nothing dropped silently

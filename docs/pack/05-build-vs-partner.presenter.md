# Build or partner?

- Partner on commodity AI; own the data and the leverage of it
- This product is DockMaster's own knowledge: what a work order means, how labour becomes an invoice
- Let a partner build that, and the crown-jewel knowledge sits on someone else's balance sheet
- The tool layer is the public API DockMaster never built, core infrastructure
- Fits the group: build in-house, reuse across the portfolio

### Where partnering stays right

- Voice stays with Blu; our layer feeds Blu context, it does not compete

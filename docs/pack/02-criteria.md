# Five tests before any candidate

An AI opportunity at DockMaster had to pass all five before money goes behind it:

1. **Data moat.** It runs on data only the system of record holds: work orders, labour, parts, financials. If an outsider could build it without DockMaster's data, it fails.

2. **A named buyer with felt pain.** A specific person at the marina already losing money or sleep over this. The sale is recognition, not education.

3. **Revenue mechanics that survive contact.** Sellable as an add-on into the existing install base (~650 marinas, ~4,000 users), priced against a cost the customer already counts.

4. **Buildable small.** A first sellable version deliverable by a small team against a legacy hybrid platform. No data-science org, no replatform as a precondition.

5. **Portfolio leverage, both directions.** Inbound: which existing group AI capabilities can be redeployed into this space. Outbound: does what we build become a pattern the group can redeploy across its ~170 vertical-software companies. Reuse before build; build what compounds.

### Deliberately not a criterion

"Uses AI." If a constraint solver or a plain report solves the pain cheaper, the AI candidate dies. This is the guard against reaching for AI reflexively.

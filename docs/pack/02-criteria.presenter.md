# Five tests before any candidate

- Data moat: runs on data only the system of record holds
- A named buyer already losing money or sleep over it today
- Revenue that holds: an add-on to the 650 marinas already paying, priced against a cost they know
- A small team can ship a first version against the legacy platform
- Portfolio leverage both ways: reuse what the group has, build what the group can reuse

### Deliberately not a test

- "Uses AI". If a plain report is cheaper, the AI idea loses
